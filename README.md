# Java Music Playlist #

*About This Project*
---
This repository contains a beginner-friendly Java Music Playlist application developed for educational purposes.

The main goal of this project is to practice and strengthen fundamental Java programming concepts through a simple, practical application.

The project focuses on writing clean, organized, and reusable code by separating the program into multiple files, with each file responsible for a specific task.

Features
---
- Display all songs in the playlist.
- Add new songs.
- Remove songs.
- Search for songs.
- Shuffle the playlist.
- Swap the positions of two songs.

Java Fundamentals Practiced
---
Variables and Data Types – Storing and managing information.

Arrays – Initializing and storing favourite songs.

ArrayList – Managing a dynamic collection of songs.

Methods – Organizing functionality into reusable blocks of code.

Static Methods – Calling functionality between classes without creating objects.

Loops – Iterating through the playlist and controlling the menu.

Conditional Statements – Handling different user choices.

Switch Statements – Implementing the menu system.

Scanner – Receiving user input.

Collections Framework – Using Collections.shuffle() to randomize the playlist.

Basic Error Handling – Checking user input and handling songs that cannot be found.

Educational Purpose
---
This project is part of my journey in learning Java programming. It serves as a practical exercise in applying core Java fundamentals, improving problem-solving skills, and developing better code organization practices.

Future improvements may include file-based storage, database integration, and additional playlist management features.
